# PowerMill COM — навык и помощник 0.5.0

Работа с Autodesk PowerMill 2023 через прямой COM: чтение проектов, подготовка
траекторий, поинт-параметры, сортировка с возобновлением и роботная симуляция.
PowerMill MCP не используется.

## Обновление 2026-11-02

Объединены правила из переданного пакета 0.2.7 и более новая реализация помощника
0.4.2. Исторические разрешения из приложенного AGENTS.md не становятся
разрешением на изменение других проектов.

- Правила новой подготовки: допуск шаблона ПЛВ 0,1 мм, физические ряды
  для стратегии «По поверхности», фактическая проверка LP/CNT_Loff,
  итоговые сборки по участкам и происхождение сохранённых RobSim.
- Проверка порядка по уникальным XYZ без обязательного чтения PP.
- Дополнительные разрешённые функции чтения PowerMill.
- Сохранение ответа нативной команды до проверки постусловий.
- Закрепление ID намеренно созданных моделей при возобновлении работы.
- Сохранены проверки настроек симуляции, координат и позы инструмента.

## Установка

Скопируйте папку `skill/powermill-com` целиком в
`%USERPROFILE%\.codex\skills\powermill-com`, сохранив старую версию отдельно.
Откройте новый чат или обновите список навыков и вызовите `$powermill-com`.
Инструкции находятся в `SKILL.md`, `INSTALL.txt` и `references/`.

Помощник находится в `skill/powermill-com/scripts/powermill_com_helper`.
Требуются Windows, Python 3.12+, Windows PowerShell 5 и PowerMill 2023.
Дополнительные Python-пакеты для помощника не требуются.
Поддерживаемые COM-версии: 2023000, 2023003, 2023101;
границы подтверждённой совместимости описаны в `references/compatibility.md`.

## Проверки

Из папки `skill/powermill-com/scripts`:

```powershell
python -m unittest discover -s powermill_com_helper/tests -t . -v
```

В версии 0.5.0 пройдены 146 офлайн-тестов помощника, включая протокол
PowerShell 5 с подставным приложением, и 4 теста сборки/установки.
Проверка структуры навыка и контрольных сумм поставки пройдена.
Живые испытания PowerMill при этом обновлении не выполнялись.

`--connect` разрешает подключение, `--allow-write` — запись только в пределах
поручения пользователя. Навык и прилагаемые документы не расширяют разрешения.
В поставку не входят геометрия заказов, живые планы, журналы или checkpoint.
`MANIFEST.json` содержит SHA-256 файлов навыка;
`PACKAGE_MANIFEST.json` — контрольные суммы опубликованной поставки.
